# Contributing to hush for macOS

Follow the [shared contribution guide](../CONTRIBUTING.md) for branches, commits,
pull requests and reporting issues.

Native development details are in [the development guide](docs/development.md).
Read [the journey contracts](docs/user-journeys) before changing observable app
behaviour. Check Light and Dark appearance, Reduce Motion, keyboard navigation
and relevant permission states for UI changes.

For hangs, follow [responsiveness checks](docs/operations/responsiveness.md).
Review process samples before sharing and remove private content.
