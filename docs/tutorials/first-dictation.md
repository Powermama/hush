# Your first dictation

In this walkthrough, you will speak a short sentence into a blank note. Use
sample text so you can comfortably share a screenshot if you need help.

You need an Apple silicon Mac with macOS 15 or later. Start with the bundled
speech model; optional writing and assistant models can wait until later.

## Install and listen

1. [Download hush](https://behu.sh/), open the disk image and drag the app into
   **Applications**. Open it from there.
2. Follow the welcome flow. When you reach the voice practice, enable Microphone
   and Accessibility through the contextual setup controls.
3. Record the suggested practice sentence. You should see a listening state,
   then local processing, followed by the transcript. Practice does not insert
   text into another app.
4. Finish setup. Personas and Verified Messages are optional.

## Put words in a note

Open Notes and create a blank note. Click in its text area. Hold **Fn**, say
"Let's make room for a new idea", then release the key. With the default
shortcut and permissions, the transcript should appear in the note.

If you changed the shortcut during setup, use that shortcut instead. If text
does not appear, confirm the text field has focus and Accessibility is enabled
for the installed copy of hush. Without automatic insertion, copy the transcript
from the clipboard and paste it manually. Microphone permission is required to
capture your voice; ordinary dictation does not require Screen Recording.

Speech recognition runs on your Mac. Downloading optional models and checking
for updates use the network. Sharing a Verified Message is a separate opt-in
workflow that publishes an encrypted record.

Next: choose a writing style in Personas, or explore the optional Assistant
(Beta) setup. For a problem, [report the reproduction](../../CONTRIBUTING.md#report-safely)
with your app version, Mac chip, macOS version and selected model.
