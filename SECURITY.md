# Security reports

Please report vulnerabilities through
[GitHub private reporting](https://github.com/Powermama/hush/security/advisories/new),
which is enabled for this public repository. Reports are shared privately with
the maintainers. You can also email [hello@behu.sh](mailto:hello@behu.sh).
Do not disclose a vulnerability in a public issue.

Include the affected version or commit, impact, a minimal reproduction using
sample data and any suggested fix. Do not send signing credentials, real audio,
private messages, complete proof links or decryption keys. Discuss a safe way to
share sensitive evidence before sending it.

hush is an alpha. Reports are assessed against the current source and published
alpha; older versions do not have a guaranteed maintenance window. There is no
guaranteed response time or bug bounty. A public disclosure date should be
coordinated after the issue and affected releases are understood.

For ordinary bugs, use the issue forms and [contribution guide](CONTRIBUTING.md).
For protocol behaviour and trust limits, start with the
[architecture guide](docs/explanation/architecture.md) and
[journey index](docs/reference/user-journeys.md).
